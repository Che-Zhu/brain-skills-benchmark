# sealos-deploy 自动化部署流程

本文描述 **brain-skills-benchmark** 中 `deploy run` 的端到端行为，与 Brain UI 触发的 GitHub 部署在运行时一致，只是入口与任务存储不同。

## 阶段总览

| 阶段 | phase | 做什么 |
|------|--------|--------|
| 入队 | `queued` | 写入 deploy task（`.data/deploy-tasks/<id>.json`） |
| 运行时 | `runtime` | 创建或复用 Devbox（`sealai-deploy-*`），注入 `GITHUB_TOKEN`、Codex 环境变量 |
| 工作区 | `workspace` | 在 `/home/devbox/project` 浅克隆仓库；安装 `sealos-deploy` skill |
| 分析 / 生成 | `analyze` → `generate` | 调 Devbox 上的 **Codex Gateway**，prompt 要求跑完 `/sealos-deploy` |
| 应用 | `apply` | 读取 `.sealos/deployment-output.json` 与 `crossplane/ap.yaml`，`kubectl apply` |
| 完成 | `ship` | `status: completed`，事件与 artifact 写入 task 文件 |

若 Codex 未产出必需文件，会多发一轮 **repair** prompt；仍缺失则 `status: blocked`。

## 与 Brain UI 的差异

| 项目 | Brain UI | brain-skills-benchmark |
|------|----------|-------------------------|
| 入口 | 创建项目 / GitHub 部署侧栏 | CLI `deploy run` |
| deploy task 存储 | Postgres（drizzle） | 本地 JSON（`.data/`） |
| GitHub token | OAuth 连接表 | 环境变量 `GITHUB_TOKEN` |
| Project CR | 可先 apply Project YAML | 需自行保证 `projectName` 在集群中合理；benchmark 不自动建 Project CR |

## 必需产物（与 runner 一致）

Codex / skill 完成后，Devbox 工作区内须有：

- `/home/devbox/project/.sealos/deployment-output.json` — `GitHubDeployResponse`
- `/home/devbox/project/.sealos/crossplane/ap.yaml` — `example.crossplane.io/v1` / `AP`，`spec.input.image` + `spec.input.network`

skill 文档还可能生成 `resources.yaml`；Brain runner 当前以 **ap.yaml** 为准做 apply。

## 部署后本地验证

若你把 Devbox 内 `.sealos` 拷到本机目录 `workspaces/run-001/`：

```bash
npm run validate -- workspaces/run-001
```

`contract` 档：schema + Brain 约定；`full` 档：skill 要求的全部 JSON artifact。

## 常见问题

**Devbox 创建失败**

- 检查 `SEALOS_HOST`、`DEVBOX_TOKEN` / `DEVBOX_JWT_SIGNING_KEY`
- namespace 须为合法 DNS-1123 标签（与 Devbox auth namespace 一致）

**`gateway_unavailable` / blocked**

- Devbox 未暴露 Codex Gateway URL；检查镜像与 Devbox 平台配置

**GHCR / 克隆失败**

- `GITHUB_TOKEN` 需 `repo` 与 `read:packages` / `write:packages` 等 skill 要求的 scope

**apply 失败**

- Devbox 内 SA 对目标 namespace 需有 edit；`projectName` 须与 AP spec 一致

## 代码来源

`src/brain-deploy/` 自 [brain](https://github.com/labring/brain) 的 `apps/ui/src/lib/deploy-task` 与 `lib/devbox` 抽出并改为：

- 本地 `task-store` 替代 Postgres
- `GITHUB_TOKEN` 替代 UI OAuth 服务

后续 Brain 侧 runner 变更时，建议 diff 同步该目录。
